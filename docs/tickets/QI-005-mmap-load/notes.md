# QI-005 注意事项

- 这张票去掉的是“整文件再放进一块 `Vec`”。权重解码仍然复制。加载完成后的常驻内存是那些解码后的张量。30% RSS 要等内核直接读映射里的打包字节。
- Linux 的 VmRSS 会计入已经触碰的文件页。映射活着的时候，峰值不一定比原来的 `Vec` 加解码缓冲更小。reader 丢掉之后，文件页可以被系统回收，匿名的那份文件缓冲不再存在。
- 映射还活着时把文件截短是未定义行为。打开时已经截断的文件会报错。不要在模型还加载着的时候替换或缩短同一个文件。
- 包路径会把整个映射读一遍来算 SHA-256。校验和还在，省掉的是第二份 `Vec`。
- wasm 目标能编译这个 crate。`memmap2` 在非 Unix、非 Windows 上返回不支持。wasm 绑定如果走到按路径打开，会得到这个错误。
- 提交在 `77db1f3`。`feature/cpu-decode` 包含它。
