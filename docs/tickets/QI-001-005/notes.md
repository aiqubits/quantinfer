# 注意事项

- 整组的开关是 Qwen3-0.6B。SmolLM2 上的曲线、分项时间和 RSS 已经够用，但不能代替票面点名的模型。权重不在本机，清单里是 1.5 GB 的 SafeTensors。
- QI-002 的文件已经在分支上。它不改变运行时。在 QI-001 关闭之前，不要把它写成已验收。
- 单线程绝对 tok/s 会随机器冷热变。13.2、19.5 和 20.0 不是同一次运行。加速比只在同一次的 4 对 1 里读。2.03 和 1.98 都出现过。
- 分项计时只包住 `--profile` 的 decode。这次序列只有 8 个 token，attention 不到 1%。长上下文会改变这个比例。和 llama.cpp 的差距目前在 matmul。
- 对照 JSON 留在 `benches/llama-cpp/`。不要放进 `benches/baselines/`。
- 映射去掉的是整文件 `Vec`。常驻内存仍是解码后的权重。30% RSS 要等内核直接读打包字节。映射存活期间不要缩短同一个文件。
- 提交从 `ee63330` 起是 `6b8935a`、`77db1f3`、`b31710b`、`c0a7efd`、`25ec4fb`、`f37fe73`。阅读入口是这一目录，不再按五张票分文件夹。
